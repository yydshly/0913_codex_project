# 研究项目目录

正式项目存放在本目录，完整顺序索引统一维护在[仓库首页](../README.md#项目索引)。

目录使用 `001-project-slug`、`002-project-slug` 等固定三位编号。

- [001 · PaperRoute](001-paperroute/README.md)：浏览器 3D 送报与 AI 辅助迭代案例，附独立可玩原型；上游开源待核实，作为低优先级案例保留。另附[通用实践指南](001-paperroute/practical-guide.md)。
- [002 · Dunhuang Aura](002-dunhuang-aura/README.md)：敦煌美术风格与出图流程说明书；可复用配色、构图、提示词和修图要求，未新增绘图能力，质量与效率增益未验证。研究已总结，后续作为特定风格的美术规范与流程参考。

- [003 · Mountain Railway Diorama](003-mountain-railway-diorama/README.md)：已完成固定版本研究；独立重建“白鹭河谷”，新增同机位四季主题、季节动态，以及岩间跌水、灌草层次与三个画质观察机位，可编辑真实地形、河道和植被，观察共享风场及水面反射，保留八项能力分析与参数实验。[当前能力基线](003-mountain-railway-diorama/capabilities.md) · [本地网页运行说明](003-mountain-railway-diorama/app/README.md) · [开发与优化记录](003-mountain-railway-diorama/development-log.md)，包含跌水流纹与白沫落点同步、铁路岩石避让与水石统一遮挡、山体与坡脚连续过渡、贴坡露岩、空地与山后坡地细节及专用机位、短草斑块与真实树位关联的林下地表、地表分区与四季草地配色、树冠体积与冬季枝形、溪谷与浅湾构图、四季光线匹配、三种水流模式与五项独立精调，默认进入层峦溪谷秋季。尚未部署。

新增编号取现有项目目录的最大编号加一；既有编号保持稳定。

新增时复制[研究模板](../templates/project/README.md)，具体步骤见[新增项目指南](../docs/adding-projects.md)。
