# 研究项目目录

正式项目存放在本目录，完整顺序索引统一维护在[仓库首页](../README.md#项目索引)。

目录使用 `001-project-slug`、`002-project-slug` 等固定三位编号。

- [001 · PaperRoute](001-paperroute/README.md)：浏览器 3D 送报与 AI 辅助迭代案例，附独立可玩原型；上游开源待核实，作为低优先级案例保留。另附[通用实践指南](001-paperroute/practical-guide.md)。
- [002 · Dunhuang Aura](002-dunhuang-aura/README.md)：敦煌美术风格与出图流程说明书；可复用配色、构图、提示词和修图要求，未新增绘图能力，质量与效率增益未验证。研究已总结，后续作为特定风格的美术规范与流程参考。

- [003 · Mountain Railway Diorama / 白鹭河谷](003-mountain-railway-diorama/README.md)：独立重建可调地形的四季铁路景观；三种构图、风与植被联动、三种水流。[研究分析](https://yydshly.github.io/0913_codex_project/003-mountain-railway-diorama/) · [实际场景](https://yydshly.github.io/0913_codex_project/003-mountain-railway-diorama/scene.html) · [开发过程](https://yydshly.github.io/0913_codex_project/003-mountain-railway-diorama/dev-log.html) · [实景与导览](003-mountain-railway-diorama/README.md) · [能力清单](003-mountain-railway-diorama/capabilities.md) · [运行方式](003-mountain-railway-diorama/app/README.md) · [开发记录](003-mountain-railway-diorama/development-log.md) · [直接体验 V23 归档](https://yydshly.github.io/0913_codex_project/003-mountain-railway-diorama/archives/v23/scene.html) · [列车与站房研究](003-mountain-railway-diorama/train-station-research.md) · [下一步](003-mountain-railway-diorama/next-steps.md)。V28 修复水色、动物机械绕圈与桥面净空；V27 新增睡莲、浮叶与蜻蜓，匹配四季和雨夜；V26 新增水下鱼群、摆尾巡游与水面透视；V25 新增白鹭、野鸭和共享风场，支持动物观察与方案保存；V24 完成曲线站台、接地入口与车房细节，新增到站近看；V23 调整连续跌水岸坡并修复水网格外缘（整体自然感仍有限制），保留白沫薄片与成组消散，并保留方案存档、文件迁移与同机位比较；仍无自由绘轨或真实流体。 [版本归档与原理](003-mountain-railway-diorama/archive.md)。
- [004 · Eanpa Sky / 听雨山居](004-eanpa-sky/README.md)：实时天空与天气联动研究；我们的山居实景、雪与冰雹、地面反馈和声音。阶段已总结，附 [后期扩展](004-eanpa-sky/next-steps.md)、[实践归档](004-eanpa-sky/practice-history.md) 与 [发布说明](004-eanpa-sky/publishing.md)。 [在线研究](https://yydshly.github.io/0913_codex_project/004-eanpa-sky/) · [天气演示](https://yydshly.github.io/0913_codex_project/004-eanpa-sky/lab/)。

- [005 · Stick & Steel](005-stick-steel/README.md)：用火柴人形象构建游戏效果，已复现关节、受力、握持、攀爬与对战等机制。后续沉淀为 Skill，由 Codex 等代理驱动制作这类游戏效果视频，或构建同类火柴人风格游戏；人物与生活故事为扩展实验。[当前能力](005-stick-steel/capabilities.md) · [开发与 Skill 路线](005-stick-steel/next-steps.md) · [本地运行](005-stick-steel/app/README.md) · [验证记录](005-stick-steel/notes.md)。[在线效果导览](https://yydshly.github.io/0913_codex_project/005-stick-steel/) · [人物演示](https://yydshly.github.io/0913_codex_project/005-stick-steel/demo/?view=characters) · [配音故事](https://yydshly.github.io/0913_codex_project/005-stick-steel/demo/?view=stories)。

- [006 · 游戏效果、交互与教学体验](006-emberfall-arpg/README.md)：从原始参考、可玩 ARPG 到物理驱动的三图导览，汇总情绪价值、实时反馈与教学探索的理解。[完整研究](006-emberfall-arpg/research-summary.md) · [研究网页运行](006-emberfall-arpg/app/README.md#研究汇总网页) · [物理实验台](006-emberfall-arpg/physics-lab.md)。[在线试玩 ARPG](https://yydshly.github.io/0913_codex_project/006-emberfall-arpg/) · [在线研究导览](https://yydshly.github.io/0913_codex_project/006-emberfall-arpg/research/)。物理实验台仍为本地样件，教学效果待验证。

- [007 · Mini Moto — Pine Ridge Park](007-mini-moto-park/README.md)：已定位截图原作并体验自主比赛、头盔镜头和驾驶权切换，整理地形联动、车手能力与模拟引擎参考；公开源码许可待核实，未本地复现。

- [008 · 山地巡游实验室](008-terrain-motion-lab/README.md)：沉淀道路、地表、树木的素材、生成与表现能力；三图导览、参数演示及三份历史快照。当前为独立原型，优先完善自然效果与稳定复用。[能力清单](008-terrain-motion-lab/CAPABILITIES.md) · [效果记录](008-terrain-motion-lab/effect-log.md)。 [在线图文导览](https://yydshly.github.io/0913_codex_project/008-terrain-motion-lab/capabilities.html) · [完整山林](https://yydshly.github.io/0913_codex_project/008-terrain-motion-lab/outdoor.html?layout=valley&view=sunrise#stage)。

- [009 · 城景工坊 / 城市景点汇总 Skill](009-city-landmark-map/README.md)：汇总城市及周边值得去的景点，以图的方式展示特色、介绍与大体位置。当前为研究原型，后期需要优化实现。[实际引导与记录](009-city-landmark-map/publishing.md)。
