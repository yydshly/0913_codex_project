正式项目存放在本目录，完整顺序索引统一维护在[仓库首页](../README.md#项目索引)。

- [002 · Dunhuang Aura](002-dunhuang-aura/README.md)：敦煌美术风格与出图流程说明书；可复用配色、构图、提示词和修图要求，未新增绘图能力，质量与效率增益未验证。研究已总结，后续作为特定风格的美术规范与流程参考。
