## 最小样本

| 实验 | 输入 | 检验内容 | 证据 |
| :--- | :--- | :--- | :--- |
| 腾冲印象图 | 核实后的 6 个地标，固定画幅 | 地方身份、布局、标签 | 地标来源、完整提示词、原始输出 |
| 丽江对照图 | 同数量地标，相同风格 | 跨城市识别度与一致性 | 相同参数、全部未筛选输出 |
| 局部修改 | 改一处名称或一个地标 | 修改是否成功，其他区域是否保留 | 前后图、指令、尝试次数 |
| 民宿用途 | 明确标为虚构的测试店名，或用户授权的真实资料 | 品牌标注、位置、输出版式 | 核实状态、导出尺寸、阅读检查 |

地标信息先查证后使用。不承担导航的图片明确写“艺术示意，非导航地图”。

## 对照设计

A：普通简短提示词；B：直接采用上游流程；C：上游流程加人工核实和文字排版。C 的增益须单独记录人工贡献。

各条件使用相同模型、城市、地标要求、画幅、分辨率，各执行 3 次并保留全部结果。支持种子时固定，不支持则记录随机性。小样本仅用于探索，不能推断普遍成功率。

| 指标 | 方法 |
| :--- | :--- |
| 地名准确率 | 正确名称数 / 全部可见名称数 |
| 地标识别度 | 对带来源参考图人工核对，记录评审者与理由 |
| 元素完成度 | 记录遗漏、重复、错误替代 |
| 空间关系 | 核对明确要求的方向、相邻和跨河关系 |
| 系列风格 | 视角、配色、材质、标题布局采用统一量表，注明主观性 |
| 修改保留度 | 检查目标与非目标区域变化 |
| 交付成本 | 分别记录模型费用、等待时间、生成次数、人工工时和修改轮数 |

## 展示归因

参考图、直接生成图和人工修改图分别标注来源、模型、版本、日期与修改。不得把独立生成作品称为上游输出。样例完成后再更新首页预览。
