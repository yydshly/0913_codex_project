# 001 · PaperRoute 可玩研究版

本目录同时提供 **3D 送报游戏**与中文研究介绍。游戏是本仓库独立实现的简化原型，使用程序生成的场景、自行车、角色和障碍；不是从原站提取的游戏源码或模型。

想基于现有原型学习开发流程，阅读[拆解与实践指南](../practical-guide.md)：包含六轮任务、可交给 AI 的具体指令、参数对比方法和实际验收步骤。指南中的改进任务尚未实施。

## 本地运行

要求 Node.js 18 或更高版本、支持 WebGL 2 的浏览器。首次运行在本目录执行：

```powershell
npm ci
node build.mjs
node preview.mjs
```

打开预览进程输出的地址，默认 `http://127.0.0.1:4173/`。首页即游戏，点击“开始送报”直接进入，不需要邮箱或账号。预览只监听本机；关闭进程后地址不可用，当前尚未发布在线演示。

如端口被占用，可先设置 `$env:PORT = '4174'`，以实际输出为准。游戏使用 ES Modules，必须通过 HTTP 访问，不支持直接双击游戏 HTML。

- 游戏入口：`/`（[源码 index.html](index.html)）。
- 研究介绍：`/research.html`（[源码 research.html](research.html)），也可点击游戏右上角“研究介绍”。
- 修改源码后重新执行 `node build.mjs`，再刷新预览。

## 怎样玩

| 操作 | 键盘 | 鼠标 / 触屏 |
| :--- | :--- | :--- |
| 转向 | ← → 或 A / D | 拖动画面；点击“左侧”“右侧”驶向对应侧 |
| 投报纸 | 空格 | 点击“投报纸” |
| 加速 | 按住 ↑ 或 W | 点击“加速”切换 |
| 慢行 | 按住 ↓ 或 S | 点击“慢行”切换 |
| 暂停 / 恢复 | P 或 Esc | 右上角暂停与继续按钮 |
| 音效 | — | 右上角开关，默认关闭 |

自动前进。靠近同侧有旗子的信箱，绿色提示出现时投递；左侧订户需要驶到左侧，右侧同理。HUD 显示下一个信箱方向、距离、库存和路线进度。

## 本地规则

这些是本项目的简化规则，并不声称与上游完全一致。

- 一周七天，每天路线长 560 个场景单位，首日 10 位订户、3 条生命、16 份报纸。
- 成功投递获得 100 分，连续送达倍数最高 ×5。投空会消耗报纸并中断连击。
- 经过信箱后超过投递窗口则算漏送，未送达订户在次日流失。
- 汽车、坑洞和小狗是可碰撞障碍；撞击扣 1 条生命并提供短暂无敌期。
- 当天全部送达奖励 2,500 分，增加 1 位订户并恢复 1 条生命（上限 3）。
- 每日结束提供 S/A/B/C 评级；生命或订户耗尽则结束一周。通关七天显示周结算。
- 失焦或切到其他页面时暂停。支持重新开始一周；进度只保留在当前页面内存中，刷新会重置。

## 实现与构建

| 文件 | 用途 |
| :--- | :--- |
| `index.html`、`game.css` | 游戏画面、HUD、控制、开始 / 暂停 / 结算界面 |
| `game.js` | Three.js 渲染、程序化模型、输入、投报动画与音效 |
| `game-state.mjs` | 骑行、投递、碰撞、跨日和失败状态 |
| `game-state.test.mjs` | 核心规则与七日状态流转测试 |
| `research.html`、`styles.css`、`app.js` | 之前完成的中文研究展示与页签切换 |
| `build.mjs` | 将页面、脚本、上游观察截图及 Three.js 输出到 `dist/` |
| `preview.mjs` | 本地 HTTP 预览服务 |

依赖固定为 `three@0.180.0`，`package-lock.json` 已保存。构建复制库模块及 MIT 许可证到 `dist/vendor/`，游戏不依赖 CDN 或在线数据服务。构建输出使用相对资源路径，可部署到静态站点子路径。原始截图仍在 [assets/](../assets/README.md) 管理。

## 已执行的验证

2026-09-13，Windows、Node.js v22.15.0：

- 依赖安装和静态构建成功，游戏与研究页面资源可通过本地 HTTP 访问。
- 六项核心逻辑测试通过：投递判定 / 冷却 / 防重复、暂停、碰撞、订户流失与次日状态、无障碍条件下连续七日流程、库存耗尽与失败。
- 七日测试为隔离障碍的状态验证，不能当作真人无伤通关或难度平衡结论。
- 浏览器实际观察了 3D 场景、开始骑行、左右控制、慢行、投空、成功投递、碰撞扣血、暂停与恢复。
- 一次实际成功投递得到 1/10、100 分、剩余 15 份报纸，见[游戏实拍](../assets/07-local-gameplay.jpg)。
- 未做真机触屏或持续帧率测量，没有多人联网、云存档或排行榜服务。

测试命令：

```powershell
node --test game-state.test.mjs
```
