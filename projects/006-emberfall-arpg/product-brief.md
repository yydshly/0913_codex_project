## 产品定义

面向喜欢探索、战斗与角色成长的单人玩家，制作一款等距视角、暗黑风格 ARPG。玩家从营地出发，通过地形与线索选择路线，在战斗中取得进展，并在回营后看到行动留下的变化。目标玩家画像为工作假设，尚未做用户访谈。

主要参考《恐怖黎明》的探索组织与《恶意不息》的空间层次；美术氛围和持续成长参考范围见 [对标记录](exploration-and-benchmarks.md)。本项目不以复刻这些商业产品的全部规模为目标。

## 本次定制的第一份交付

**样段名：余火商道。任务：查明哨站失联原因，救回信使，恢复商道联络。**

营地 → 商道分叉 → 正路桥口或侧路坡道 → 哨站庭院 → 建筑内部救援 → 开启返回捷径 → 营地出现信使与新情报。

| 范围 | 交付要求 |
| :--- | :--- |
| 空间 | 可进入的哨站建筑；连续坡道高差；两条进入路线；从内侧打开的回营捷径 |
| 战斗 | 桥口基础遭遇与庭院组合遭遇；侧路可绕开第一组，但不能绕过救援前的庭院挑战 |
| 探索 | 一处能从主通路察觉线索的隐藏补给；支路有回报，未发现仍可完成任务 |
| 世界反馈 | 被救信使从哨站消失，在营地固定地点出现；首次交付解锁一条新情报，唯一奖励不重复领取 |
| 成长 | 样段阶段复用现有斩击、闪避、星陨、药剂及背包；两套新打法列入后续 S5 |
| 交付形式 | 本地浏览器可玩版本、设计与验证记录、实际截图；最终发布形式另定 |

期望首次游玩 5–8 分钟；后续首章目标 30–45 分钟。均为设计目标，需以首次真人体验记录调整，不通过强制等待或拉长走路凑时长。

## 工作基线与待定条件

| 条件 | 本轮处理 | 后续需要明确的时间点 |
| :--- | :--- | :--- |
| 单人、等距、探索方向 | 沿用已讨论方向，制作具体样段 | 试玩后可根据反馈调整 |

| 美术与声音 | 先用原创／已具备合法来源的样板资产；逐项记来源与许可 | 精修前确定风格样板与外部资产范围 |

| 商业化、账户、联网 | 当前不进入样段范围 | 产品立项与发布范围确定时再讨论 |
| 引擎 | 先验证现有技术能否支持连续地面高度与遮挡处理 | 以功能和性能证据决定是否需要调整 |

## 验收与协作

开发按路线图 S0—S6 推进；每阶段提交可体验结果、实际证据与遗留问题。通路、战斗反馈、世界变化和存档分别验收，详见 [acceptance.md](acceptance.md)。样段通过后才批量扩展首章。

用户决定定位、风格和范围上的关键取舍；实现方推进常规实现、记录假设与复测结果。新增要求要写明影响哪些任务和验收项，先更新设计基线再实现。当前“继续”用于推进这份任务书、布局与验收设计，不记为每一项候选数值或商业条件都已获得确认。
