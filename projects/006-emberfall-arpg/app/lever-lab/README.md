# 看得见的物理 · 杠杆实验室 0.1

独立 Windows 二维交互实验台，2026-09-14。直接拖动重物和支点，观察重力、力臂、运动与实验对比。没有角色移动、关卡或下一步页面。

## 启动

项目内启动文件为 `dist/LeverLab.exe`；便携包解压后直接双击 `LeverLab.exe`。运行文件、相邻 `LeverLab.pck` 及两份 Godot 许可文件必须一起保留；启动不需账号、联网或安装引擎。发行包尚未发布至网络。

当前便携包使用官方 Godot 编辑器二进制作为运行时并加载独立 PCK，EXE 约 156 MiB，属于本地验证包；不是裁剪过的正式发行导出，窗口带 DEBUG 标识。没有使用已付费资产。

源码可用 Godot 4.5.1 打开本目录的 `project.godot`。仓库不提交下载的引擎或生成包。

## 怎么探索

1. 点击“运行”，看初始的 3 kg 和 2 kg 重物怎样转动；随时暂停。
2. 直接拖动重物或三角支点。重量用右侧滑块调整；选中物体后也可用方向键或两个微调按钮移动。
3. 选择 ¼× 慢放或单步，看力臂与箭头如何对应运动。
4. 运行至少 0.1 秒后“保存为 A”，再改变当前 B，重新运行；两幅装置与两条曲线使用相同模拟时间比较。
5. 点击“回放”或拖动下方时间轴，查看当前 B 已记录的运动。回放时暂停修改布局；“停止回放”返回当前实验末态。

“回到起点”只重置 B 的运动；“恢复初始布局”恢复 B 的初始参数，两者均保留 A。“清除 A”回到单幅实验台。当前 A/B 记录保存在内存，关闭窗口会清空，尚未提供实验文件导出。

空格运行／暂停；当键盘焦点在按钮上时，空格按标准行为激活该按钮。滑块获得焦点后，左右键用于调整滑块。F12 截图保存到 Windows 用户目录下 `Godot/app_userdata/看得见的物理 · 杠杆实验室/captures/lever-lab-live.png`，后一次覆盖同名截图。

## 实验规则与局限

- 两个重物以质点近似，固定在梁的两侧；梁长 6 m，忽略梁自重和弹性。矩形重物是质量标记，力作用点按梁上连接位置计算。
- 重力始终竖直向下，箭头长度与重力成比例。力臂显示支点到力作用线的水平距离，随倾角改变。力矩为重力乘该距离。
- 根据合力矩、两质点的转动惯量和黏性阻尼更新运动；限位为 ±0.42 rad（约 ±24.1°），到限位时去掉继续撞向限位的速度。
- 有阻尼和非弹性限位，机械能不守恒；本轮未显示能量数值。不是通用刚体仿真或精密测量工具。
- 支点限制在两重物之间，各至少留出 0.3 m。移动物体、改变重量会重置 B 的运动和记录；运行中拖动时临时暂停，松开后恢复运行。
- 固定 120 Hz 模拟，30 Hz 记录，每次最多 12 秒模拟时间。¼× 只改变播放／推进速度，不改变物理参数。
- A 的记录短于当前时间时，装置停在 A 末帧，明确标记；曲线不外推。画布自动使用共同缩放以保证整个 A/B 装置可见。
- 只验证基本物理和交互行为，尚未做教师评审、课程对齐、真实学习者理解度或长期记忆测试。
