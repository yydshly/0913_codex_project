## 为什么调整

用户先后指出图片分镜和任务型工坊仍未达到预期，询问更容易实现的方向，并确认继续“让物理变得可见”。当前交付改为直接操作的二维实验台，原 ARPG 与教学冒险保留为探索历史。

情绪价值仍是好奇、发现规律的惊喜与掌控感。用户可以自主选择改变什么；解释围绕刚刚发生的现象展开。是否产生这些感受、是否理解规律仍需真人观察，不以运行成功代替。

## 已实现的体验

| 操作 | 可观察的结果 |
| :--- | :--- |
| 拖动两个重物或三角支点 | 位置、力臂和两侧力矩实时更新；松开后按原运行状态继续 |
| 改变左右质量 | 0.5–8 kg，重力箭头与数值同步变化 |
| 运行、暂停、单步、¼× 慢放 | 同一套物理规则按指定节奏推进，不改变质量或力的大小 |
| 显示力与运动轨迹 | 看见竖直重力、水平力臂，以及质量连接位置的运动轨迹 |
| 保存 A，再调整 B | 两幅装置、两条曲线并排比较；A 保留当时的参数与运动记录 |
| 回放与拖动时间轴 | 读取已记录的运动；不会重新模拟，也不会改写当前实验 |
| 等力矩示例 | 4 kg × 1 m 与 2 kg × 2 m，显示不同重量也能平衡 |

每次修改布局从水平静止状态重新记录 B，避免把改变位置时人为加入的能量误算成自然运动。运行中的拖动会临时暂停；A 的记录不受影响。A/B 记录目前只在本次会话内保留。

## 验证与边界

23 项自动检查通过：物理方向与平衡、限位、采样、暂停、慢放、单步、回放、拖动坐标、键盘微调及 A/B 记录隔离。另验证独立 EXE 能加载相邻 PCK 启动。原生窗口中检查了参数变化、保存 A、恢复 B、运行及两条对比曲线；截图路径问题已修复，并验证实际写出 PNG。

简化模型采用固定在梁两侧的质点、无自重刚梁、固定支点、黏性阻尼与非弹性角度限位。未实现任意刚体堆叠、弹性、能量图、实验文件导入导出、课程体系、教师评审或学习效果测评。

Godot 4.5.1 作为当前样件的实现工具；不是对后续全部产品路线的长期承诺。当前包使用较大的编辑器运行时加载独立内容包，便于本地体验；正式发行导出、签名与精简体积尚未完成。

## 下一步判断

先观察使用者能否独立完成“改变一个条件 → 观察 → 保存对比 → 解释差别”。优先记录拖动是否顺手、箭头与力臂是否看得懂，以及是否愿意主动尝试新的配置。根据证据改进这一个实验，再决定是否加入摆动或碰撞；暂不扩展任务或地图。
