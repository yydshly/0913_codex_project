## 验收规则

每项记录：应用版本或实际 commit（未提交则写待记录）、设备、浏览器、窗口尺寸、起始存档、操作步骤、期望结果、实际结果、证据路径、问题与复测状态。状态可用“未实现 / 待验证 / 通过 / 未通过 / 阻塞”；本文件初始状态统一为未实现，基线测量项为待验证。

阻断通行、进度丢失、奖励重复、关键交互不可用与无法辨认攻击的严重问题必须解决后再扩展章节。视觉喜好与体验评价由实际观察和用户反馈补充，不用自动测试代替。

## G0 · 基线记录（S0）

- [ ] AC-01：备份当前存档，记录固定起点与运行条件；测试后能恢复原进度。
- [ ] AC-02：记录一次从新档开始的手动流程，区分真实操作用时、暂停时间与自动模拟时间；未通关也如实记录终止原因。
- [ ] AC-03：形成最多三项优先问题，包含发生位置、复现步骤、实际截图或录像与严重程度。未观察到的问题不能填作事实。

## G1 · 通路与空间（S1，最先交付）

- [ ] AC-04：使用点击移动与 WASD 分别完成 A-B-C-E、A-B-D-R-E 和反向返回，无卡死、穿墙或走入不可达地点。
- [ ] AC-05：角色与敌人沿坡道连续贴地，平台无漂浮或穿地；不能从落差两侧隔空近战或交互。
- [ ] AC-06：进入和离开 F 建筑时，相机与屋顶处理保证角色、门和主要威胁可见；鼠标选择不被透明屋顶错误截获。
- [ ] AC-07：锁定 G 时外侧不能穿门；解锁后实体门、碰撞、寻路和小地图同时更新；站在门口解锁不把角色卡入障碍。
- [ ] AC-08：H 支路有可观察线索，发现它不是主线前置；未开启捷径也能沿来路完成返程。

S1 可用测试交互暂时开门，但必须明确标注开发状态；正式救援前置由 G3 验收后替换。不得用开发开关结果声称完成整段任务。

## G2 · 战斗（S2）

- [ ] AC-09：C 基础遭遇能识别预警、攻击生效时点与闪避结果；动画、音效和伤害时机对应。
- [ ] AC-10：E 组合遭遇中，弓手与近战的威胁不同；绕侧面、调整目标或使用技能产生可观察差异。
- [ ] AC-11：敌人能抵达与撤回合理位置，不隔实体墙伤人，不利用不可达平台持续追击；同高度射线与高差判定均有用例。
- [ ] AC-12：两条进入路线均能在正常资源规则下完成；死亡、复活和重新进入可继续，不必修改血量或冷却才能通过。

## G3 · 救援、世界反馈与保存（S3）

- [ ] AC-13：清理 E 才能通过正式交互进入 F 完成救援；再次对话不会重复完成。
- [ ] AC-14：救援后 F 信使消失、A 信使出现；回营可查看新情报。关闭任务提示仍可辨认角色变化。
- [ ] AC-15：G 从 F 内侧解锁，开放状态在换图和刷新后保留；不打开 G 也可交付任务。
- [ ] AC-16：在接任务、庭院清理、救援、开捷径和交付这些节点检查死亡、刷新、退出继续，进度符合明确的检查点规则。
- [ ] AC-17：重复交付、重复拾取、满包、离开后返回不会重复奖励或吞掉落。旧存档恢复与坏档拒绝有记录。

## G4 · 表现与完成度（S4）

- [ ] AC-18：A/B/E/F 固定机位有前后截图；建筑内外、主要道路和危险区有一致的视觉区分，角色不会持续被装饰遮挡。
- [ ] AC-19：移动、攻击、闪避、受击和死亡关键动作可辨识；环境音与战斗音可分别调节或至少明确开关，静音不阻止通关。
- [ ] AC-20：新增模型、贴图、动画与音效的来源和许可均有记录；概念图、设计图与实机截图各自标注。
- [ ] AC-21：在 G0 同条件记录载入、战斗和持续运行表现；帧率与资源预算在基线测量后填写。无测量时保持待验证，不宣称达标。

## G5 · 成长与扩展门槛（S5—S6）

- [ ] AC-22：两套候选装备／技能组合面对同一遭遇时改变实际打法，分别记录操作与体验；只增加伤害数值不算完成。
- [ ] AC-23：首次体验者能描述主目标、至少一个路线选择以及完成救援后的变化；建议后续 3–5 人观察，尚未安排。
- [ ] AC-24：记录样段真实时长与卡点，评估 5–8 分钟目标；不因时长接近目标就忽略无聊或阻断问题。
- [ ] AC-25：进入完整首章扩展前，G1—G4 的必需项通过，G5 的打法与体验有证据，严重问题已关闭；首章 30–45 分钟另行验证。

## 本轮设计文档验收

- 产品定位、首份交付、工作假设与商业待定条件可分辨。
- 布局覆盖双路线、室内、高差、隐藏补给和解锁回环，地点 ID 与文字描述一致。
- 每个开发阶段有具体操作和可观察结果，性能与真人时长没有虚构数值。
- 本地链接与设计图可打开，项目和根目录导航同步。实际检查结果追加到 notes.md。

| :--- | :--- |
