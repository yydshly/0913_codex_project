WHAT WE LEARNED / 我们的理解

工具提供能力，设计决定怎么用。

这次从效果库走到个人作品页，我们确认了三类工具的分工：Product Design 帮助探索并落实视觉方案；GSAP 编排元素随时间、滚动和操作产生的变化；Canvas UI 为合适的区域增加实时特效。我们将实际优化归纳为下面四种方式，不是四个插件，也不是四种动画。

它们不会自动理解产品，更不能保证“装完就有高级感”。应先明确用户要看什么、做什么，再选择版式与反馈，最后决定特效是否有帮助。

FOUR WAYS TO IMPROVE

四种优化方式

实验室的四阶段是“基础页面 → 设计调整 → GSAP → Canvas UI”。基础页是对照起点；下面按实际工作归纳四类优化。

01 / 内容与结构

先说清楚，能做什么。

安排标题、说明、能力和入口的顺序，让浏览者知道当前是什么、值得看哪里、下一步去哪里。

我们如何使用
把听雨山居的单图详情整理成天气选择、观察重点、实时体验与研究资料。
适合的位置
产品介绍、作品详情、功能说明、操作流程。
打开作品 → 听雨山居 ↗
02 / 视觉设计

让重要内容先被看见。

调整构图、字体、间距、色彩和图片比例。即使关闭所有动画，页面仍然应该清楚、完整。

我们如何使用
通过 Product Design 探索三套方案，选定深绿作品展览；区分主入口、缩略图与项目说明。
适合的位置
首屏、导航、作品列表、详情与手机布局。
查看实验室设计阶段 ↗
03 / 动效编排

让变化有来由。

用 GSAP 把进入、切换和返回连接起来，帮助用户理解状态变化；节奏和反馈比持续运动更有用。

我们如何使用
标题错峰进入、作品显现、图片展开到详情、天气说明渐显，关闭后恢复阅读位置。
适合的位置
滚动叙事、画廊、菜单、按钮反馈与状态切换。
体验 GSAP 编排 ↗
04 / 场景特效

让氛围与内容对应。

Canvas UI 提供云雾、冰霜、火焰、水波等实时视觉组件。选择与内容相关的少量效果，再调整强度。

我们如何使用
白鹭河谷叠加 Clouds；听雨山居雪景叠加 Frost，鼠标经过可融开，人物作品保持原始画面。
适合的位置
主题封面、场景照片、局部强调与探索反馈。

选用时要记住

效果数量不等于页面质量。标题、按钮和正文必须可读可操作；支持关闭动效与系统减少动态偏好。静态截图不是持续运行演示，视觉叠加不是天气、机械或物理仿真。本次实现使用 React，不代表已经验证 Vue／Svelte 的相同表现。
