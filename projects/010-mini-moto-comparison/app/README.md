# 010 · 松脊越野公园运行说明

独立网页：实时 3D 公园、四车三圈短赛与研究说明。Node.js v22.15.0 已验证，浏览器需要 WebGL。Three.js r185 和 OrbitControls 随项目保存，无需安装依赖，运行时不依赖 CDN。

## 启动

在本目录执行：

```powershell
node serve.mjs
```

默认打开 `http://127.0.0.1:4320/app/`。该服务仅监听本机，不是公开网站；入口 HTTP 200 已验证。若端口冲突可设置 PORT，以服务实际输出为准。

## 体验顺序

### 发卡弯自由驾驶练习

新增入口 `http://127.0.0.1:4320/app/ride.html`，原研究页顶部也有链接。W / ↑ 油门，S / ↓ / 空格制动，A D / 方向键自由转向；R 回最近检查点并加 3 秒，P 暂停。触控按钮支持按住，失焦暂停并释放输入。

先看内线或外线示范，再点击自己驾驶；示范途中按驾驶键也能接管，但成绩会标为自己驾驶。按顺序通过六道检查点后结算，草地降低速度，外围护栏阻挡并加 2 秒。结果记录用时、距离、泥地/草地停留和碰撞，刷新清空。两条示范用同一运动模型运行，成绩不是硬编码或最优解。

核心新增文件：ride-model.mjs（自由运动、抓地、碰撞边界和检查点），ride.mjs（场景与输入），ride.html / ride.css（驾驶界面），ride.test.mjs（8 项模型测试）。摩托主体复用本项目 makeBike，未引入额外第三方依赖。

```powershell
node --test ride.test.mjs
```

### 原公园比赛与研究页

1. 观看默认比赛；点击排名中的名字选择观察车手，全景可拖动、缩放。
2. 点击“抬高坡道”，镜头转到带橙色旗帜的试验段；道路和车手使用新高度。
3. 点击“计算同车手单圈对照”，比较默认与当前条件。参数变化使旧结果失效。
4. 选择“雨后比赛”，观察抓地、圈时、材质和雨丝；切换泥地或碎石仅改变试验段。
5. 接管阿岚：W / ↑ 加速，S / ↓ / 空格制动，A D / 左右键路内转向，Esc 交回。手机可按住画面上的油门/制动/方向按钮。
6. 声音默认关闭，由点击开启；切换白模或网格观察场景结构。4× 演示速度可更快看完整场结算，手动接管自动恢复 1×。

切换条件会重新起跑，保证同一场比赛使用统一条件；暂停冻结比赛，镜头仍可观察。失焦释放输入并交回自动，后台不补算经过的比赛时间。没有持久化存档。

## 模块和构建

| 文件 | 职责 |
| :--- | :--- |
| index.html / styles.css | 中文研究内容、响应式控制与来源 |
| model.mjs | 闭合道路、坡度/抓地限速、车手运动、计圈与结算、单圈对照 |
| scene.mjs | 摩托/车手、松林、维修区、道路、材质、镜头、雨丝与粒子 |
| app.mjs | 控制绑定、固定步长循环、排名与解释、音频、输入交回 |
| model.test.mjs | 完整比赛、联动、道路几何与手动切换等 9 项测试 |

```powershell
node --test model.test.mjs
node build.mjs
node check.mjs
```

输出为本目录 dist/；构建把图片、纹理、库与研究记录打包为相对路径，兼容独立静态托管及根仓库的编号子路径汇总。没有修改其他项目应用或运行全仓库发布。

## 实现边界

原公园比赛为道路约束的简化运动，车辆不能任意离路；新增驾驶练习允许自由驶离道路并与外围边界碰撞。两者均不模拟完整刚体、轮胎悬挂或离地跳跃。原比赛四名车手使用不同偏移行驶，未实现动态避让与车辆碰撞。雨丝和湿润材质不是流体或场景反射，声音为简易 Web Audio 合成。

通用 Three.js 库与 CC0 纹理复制自 008 的已归档资源，保留许可证及哈希清单；其他应用代码独立编写，没有移植原作发布包或模型。参见[素材来源](../assets/README.md)和[实际验证记录](../notes.md)。驾驶练习已检查实际画面、两条示范、键盘接管、暂停和救援；原比赛逐项浏览器验收、声音听感、真机触控与完整手动完赛尚未执行。
