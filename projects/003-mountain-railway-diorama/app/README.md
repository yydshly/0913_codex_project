# 003 · 白鹭河谷：四季微缩景观与场景编辑

当前实践是独立编写的 Three.js r185 场景“白鹭河谷”，以河岸观景铁路为用途。保留原理分析页及五步搭建功能，打开实景页直接进入层峦溪谷秋季完整场景，可在顶部切换四季主题。

## 四季主题

四季保持同一地形、轨道和建筑布局，默认用同一全景机位比较，切换不会重建地形。取消“切换时使用同一全景机位”即可保留自己的观察位置。

| 主题 | 树木与地表 | 水体、光照与天气 |
| :--- | :--- | :--- |
| 春 · 花溪 | 较疏嫩叶、部分花树、湿润河岸 | 较快水流、柔和晨光与轻雾 |
| 夏 · 浓荫 | 完整浓绿树冠、绿色草岸 | 深色水体、较高太阳与清晰日影 |
| 秋 · 金岸 | 按树木错落变色、少量落叶、金色草岸 | 较缓水流、低角度暖光 |
| 冬 · 初雪 | 季节过渡完成后落叶、裸枝、朝上表面覆雪 | 岸边薄冰、缓流水面、冷光与雪花 |

主题联动颜色、树冠保留比例、风力、水流速度、灯光、雾、地表材质和冬季粒子。季节过渡使用统一权重，枝叶与阴影共用落叶规则。地形编辑、天气和风水控件仍可单独使用。

覆雪与岸冰使用材质表现，花树使用花色叶簇；花瓣与落叶使用简化粒子及地面小片，没有精细花瓣模型、积雪厚度或结冰物理求解。四季主题是美术预设，不表示所有地域都遵循这种季节变化。

## 四季动态与氛围

- 春季：树冠附近循环飘落花瓣，树下可见少量粉色地面花瓣。
- 秋季：飘落叶片与树下地面叶片，数量可分别控制。
- 夏季：萤火只在暮色与夜间出现；“看夏夜萤火”切换夏夜并进入河岸近景。
- 冬季：雪花数量由动态细节滑块控制；设为 0 可关闭降雪，覆雪地表仍保留。
- 雾量：0—200% 调整当前主题的距离雾，不是体积雾模拟。

动态数量与地面覆盖均为 0—100%。地面叶片按树木位置和地形高度生成，避开水域与轨道中心；地形重建会更新这些细节并释放旧几何。暂停会冻结粒子的动画时间。花瓣、落叶、萤火和雪花为循环视觉动画，没有生物行为、碰撞或长期累积求解。

## 可以实际调整什么

| 控制 | 实际改变 |
| :--- | :--- |
| 地形起伏 | 山丘高度与坡度；铁路周边继续整平 |
| 河道半宽、弯曲 | 河面、河床、岸线、岸石与植被位置一起重建 |
| 水位落差 | 上游水位与跌水高度 |
| 乔木数量 | 重新放置实际树木，避开铁路、水域与车站 |
| 三种基底 | 开阔河口、岩岸溪谷、沙洲浅湾的参数组合 |
| 风力、风向、阵风 | 枝干弯曲、叶片颤动、芦苇倾斜、水面波纹及雨丝倾斜 |
| 水流速度 | 水流纹理与漂浮泡沫的运动速度，独立于风力 |
| 天气、列车与镜头 | 昼夜雨景、车速、暂停、网格、近景与自动观景 |

布局修改会重新生成场景几何，不是改一张示意图。连续拖动停止约 220 毫秒后更新，释放旧几何、材质、纹理与反射目标；保留列车的运行位置。轨道控制点仍固定，尚未提供拖拽绘制轨道或任意地形雕刻。

风场由时间、位置、强度、方向和阵风组成。柳树柔韧系数为 1，普通乔木为 0.5，芦苇为 1.9；根部固定，越高的位置弯曲越明显。枝叶与阴影使用同一位移。水流速度设为 0 时仍可能存在风生波纹，暂停场景可冻结整个动画时间。

## 本轮视觉变化

- 从中央高山、锥形树林和橙色桁架桥，改为开阔河口、低矮河岸、细碎叶簇、芦苇和浅色拱桥。
- 树木包含树干、分枝和带透明裁切的叶簇；多重采样减轻细叶边缘锯齿。
- 水体包含多层扰动、深浅色、岸边泡沫、流动水纹、跌水与水雾。
- 下游水面每约 120 毫秒更新一次真实场景倒影，结合环境反射和视角相关反射强度。上游与跌水不使用这个平面倒影。
- 默认打开地形面板，五步搭建可展开，减少底部文字对画面的遮挡。

这是风格化观景原型。没有真实流体、树木力学、侵蚀、多车调度、隧道或音效；预设共用闭合轨道，尚未成为通用场景编辑器。未声称细节与美术完成度已达到上游原作。

## 第五版观景顺序

进入场景后选择秋季，在四季按钮下依次点击「河谷全景」「河岸植被」「岩间跌水」。窄窗口可以收起「编辑场景」面板查看完整画面。

新增植被共用原风场和季节权重；地形重建时，岩石、灌草及近景目标一起更新。树木数量是目标上限，实际布点受铁路净空和最小间距限制。水流分束通过错落高程、岩石遮挡和移动泡沫表现，并未求解水绕过岩石的物理过程。

## 水流模式与扩展

四季面板下可选择连续跌水（默认）、浅滩缓流、岩间分流。先点击「近看当前水流」再切换模式，可保持同一机位比较。浅滩降低实际落差，面板会显示结果；岩间分流仍是实验性视觉方案。

`scene-water-modes.mjs` 集中定义模式参数，`scene-world.mjs` 据此生成水面和河床；`scene-water.mjs` 控制泡沫、裁剪和飞沫，`scene-landscape.mjs` 决定是否布置挡水岩块。新增模式需要扩展对应配置、界面和必要的几何/材质逻辑，并补验证与开发记录。

## 第八版：水流精调

在水流模式下方展开「精调当前水流」，可以分别调整水层厚薄、白沫量、水雾量、倒影强度和水纹强度。调整即时作用于画面，无需重建地形；「恢复当前模式默认」只重置所选模式。各模式在本次打开页面期间独立记住设置，刷新会清空。

连续跌水采用上游较慢、跌落加速、入潭逐渐减速的行程曲线，水纹与漂浮泡沫共用这一曲线。改变流速不再让水纹突然跳位。厚薄控制深浅水色和水层观感，并非真实体积厚度；浅滩保持无跌水雾。

## 第九版：河岸与入潭细节

沿用秋季连续跌水样板，水面从原来的固定横向边界延伸到实际浅水岸缘，浅水处波动与倒影减弱；岸缘加入湿润色和材质变化。降低连续长亮条，入潭白沫按生命周期逐渐出现、向两侧散开、变淡消失。

保持原植被布点参考，根部贴合新地形；岸石随岸缘调整埋深。地表细分提高至 120×300，180 个白沫小网格改为一次实例化绘制；整体性能收益尚未测量。平面倒影仍有简化轮廓。

网页「开发记录」的 V9 条目显示修改前后实景截图，也可依次使用「水流近景」「河岸植被」「河谷全景」查看当前场景。截图动画帧不同，不是逐像素对比。[过程和问题修正](../development-log.md) · [三个机位截图](../assets/README.md#第九版河岸衔接与白沫消散)

## 第十一版：树冠与冬季枝形

树冠使用多个朝向的弯曲叶簇，按内外位置调整明暗；树型、区域色调与季节共同影响花色、秋色和疏密。主干分段弯曲，分枝连续并逐级变细，冬季落叶后可看到完整枝形。枝叶和阴影保持同一风场、落叶规则。

先查看「河谷全景」中的春夏秋冬，再进入「河岸植被」检查近景。宽窗口也能收起编辑面板。两种景观共八张四季实景与秋冬近景保存在开发记录 V11。

本轮更换了树形与布点随机数组织，同一版本换季位置不变，但不与 V10 逐树对应。叶簇的片面感、裸枝折线感和新增几何开销仍是后续优化项。


## 第十二版：地表分区与四季草地

地面由四季各自的草坡、林地、裸土和岩面基础色混合，取消在统一绿色上叠加季节乘色。陡坡增加露岩，近岸增加裸土与湿润过渡，植被分区影响林地色，草丛同步换季。秋季保留成片残绿，冬季未覆雪处使用枯草底色。

本轮沿用树色、水色及照明参数，先检验地表变化对整体画面的影响；树木位置、河床和铁路没有改动。林地分区依据种植区域和密度近似，不逐树计算，也不是烘焙阴影。向阳明暗仍来自原有实时光照。

32 项检查通过；开发记录 V12 提供同机位修改前后、两种景观八个四季组合、代表性日光/夜景/雨景和河岸近景。近看草地仍有平滑材质感，站点生活场景留待下一轮。


## 第十三版：短草、林下暗土与落叶

在现有「河岸植被」机位查看地面：新增疏密短草，按实际树木位置形成林地色块与纹理，树下落叶更细碎、更暗并贴合坡面。草丛与落叶保留原四季和风场驱动；地面覆盖滑块继续控制春季花瓣与秋季落叶。

短草根部逐点贴地，避开铁路、水域、树干和车站主体。树下覆盖使用树根与树高近似，替代 V12 仅按种植区域估算的方式。地形更新会一起重建，原树木位置未因添加短草而改变。

34 项检查通过，八个四季全景及三个近景已实测。V13 溪谷截图沿用用户选择的岩间分流；刷新默认仍为连续跌水。草叶与落叶几何增加，尚未做性能基准与远近细节分级。


## 第十四版：林间空地与山后坡地

场景主题下新增「林间空地」「山后坡地」入口。空地机位根据实际树木分布寻找较开阔且平缓的位置，山后机位随山体高度调整；编辑地形或切换构图后更新。取消「切换时使用同一全景机位」可停留当前新机位比较四季。

全岛按坡度、树冠覆盖、岸距和轨道距离补充低矮灌木、坡草、露岩与少量倒木。较陡切坡使用薄嵌岩和局部起伏；低缓浅湾不强行添加与溪谷等量的岩石。新灌木有简化枝干，枝叶继续受四季和共享风场驱动，岩石与倒木延用朝上表面覆雪。

36 项检查通过；另外检查三种默认构图中新增岩石变换后的顶点，距轨道中心最近 2.768 m，未越出岛边界。此数值不代表所有编辑参数组合。程序化切坡仍有简化造型，新增细节增加构建与几何开销，尚未做性能基准。


## 第十五版：山体与坡脚

进入「山后坡地」查看铁路旁的圆滑坡脚与较宽切坡，进入「林间空地」观察草丛、林缘与露岩衔接。地形编辑会同步更新树根、草根与贴坡岩石。切换四季仍共用同一地形，取消「切换时使用同一全景机位」可停留山后比较。

保留旧的树木布点参考地形；实际坡面改用距离铁路的平滑上升包络，局部高山会降低。露岩几何逐顶点投影到底面，替代旋转石块贴在陡壁上的方式；小碎石采用最小避让余量。覆雪与湿润继续叠加到岩面材质。

38 项检查通过；开发记录 V15 有 13 张实际画面及修改过程。山后坡度下降只在默认溪谷指定采样区域量化；近河路堤、岛体侧壁和近景草叶重复仍需优化，未做移动设备性能验收。


## 第十六版：铁路净空与水石一致性

三种水流模式仍可分别精调。岩间分流现在使用三个低矮露岩，水面缺口跟随实际石块，取消固定竖向水束裁切。连续跌水、浅滩缓流不放置这三个分流石；岸石沿用统一铁路避让规则。

scene-rocks.mjs 输出共享椭球布局及水面截面，岸石和分流石完整半径加 2.45 m 保护余量避让轨道采样线。水面读取同一障碍，分流石另作片元级裁切，白沫遇障碍隐藏并向侧方偏转。跌水有独立色调和较高粗糙度，降低浅水黄底与塑料高光。

40 项检查通过，新增 36 组构图/基底/水流组合的岩石完整顶点检查。没有真实压力、蓄水与溢流求解，不能模拟用户任意堆石完全堵河。V16 开发记录含修复前后近景与其他代表视角，不是所有组合的视觉验收。

## V17：水面自身的流动层次

新增纵向流纹、沿水面法线的小幅起伏和连续加减速，岸缘、岩石附近减弱位移；落点白沫和飞沫读取与水面相同的横向跌落偏移。参数入口不变，可将白沫、水雾都设为零观察水体自身运动。

43 项检查通过，包含真实水面网格属性、横向行程反算和落点对应；暂停时两次水面局部截图字节一致。浏览器查看四季连续跌水、岩间夜景/雨景、高落差、浅湾和最大风力/阵风/水纹配零流速。保存 12 张实景到 V17 记录。代表检查不覆盖所有参数排列，也不构成性能基准。
