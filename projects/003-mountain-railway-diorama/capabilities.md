## 定位与来源

当前成果是可在网页运行、可调地形与环境的风格化铁路观景原型，适合场景表现研究、主题景观试作和交互展示。它具备场景生成与调参能力，尚未形成完整的场景创作产品。

上游为 [iamtechartist/mountain-railway-diorama](https://github.com/iamtechartist/mountain-railway-diorama)，研究固定于 commit `6e8b0fbb806e486d7819b6d297b92f4ecf3d258b`（package 2.2.0），MIT 许可。本地“白鹭河谷”为独立重建，使用随项目提供的 Three.js r185。上游的隧道、神社、自适应画质等能力不能直接计入本地成果；来源与许可见 [研究总览](README.md) 和 [图片来源](assets/README.md)。

## 当前已经能做什么

| 能力 | 网页中的实际行为 | 实现依据与边界 |
| --- | --- | --- |
| 景观构图 | 层峦溪谷、疏林浅湾、原有河谷三种构图 | `scene-composition.mjs`：预设山峰、森林分区、配色与镜头；不能拖动单座山 |
| 地形编辑 | 修改起伏、河道半宽/弯曲、落差、乔木目标数；三个基底预设 | `scene-world.mjs`、`scene.mjs`：地面、河床、岸线和植被重建；非自由雕刻，铁路仍固定 |
| 铁路运行 | 两节列车沿闭合轨道运行、到站停靠、调速与观察 | `scene-train.mjs`、`scene-service.mjs`：路径运动；无绘轨、多车调度或隧道编辑 |
| 三种水体 | 连续跌水、浅滩缓流、岩间分流；各自精调厚薄、白沫、水雾、倒影、水纹 | `scene-water-modes.mjs`、`scene-water.mjs`：风格化材质与动画，厚薄是观感参数 |
| 水石关系 | 岩石避让铁路，水面排除固体内部，流纹局部偏转 | `scene-rocks.mjs`：共享障碍布局；不能推演堵河后的蓄水与溢流 |
| 水面运动 | 纵向流纹、小幅起伏、连续加减速；落点白沫和飞沫同步；不规则白沫成组出生、沿流向散开 | V17 + V19；180 个实例、沿水面切线贴合并检查整片避石边界；非流体或水膜求解 |
| 植被与风 | 枝叶、芦苇、水纹与雨丝响应共享风向、风力、阵风 | `scene-vegetation.mjs` 等：位置与柔韧系数控制动画；水流速度独立于风，不是树木力学 |
| 地表与全域细节 | 草地分区、短草、树下落叶与暗土、空地和山背面细节、连续坡脚及贴坡露岩 | V12—V15；程序化分布，不能逐物件选中编辑 |
| 四季与天气 | 春夏秋冬主题，推荐光线与独立天气控制，花瓣/落叶/萤火/雪花及雾量 | `scene-seasons.mjs`、`scene-details.mjs`：美术预设；无雪厚累积、结冰物理或真实气象 |
| 镜头与观察 | 自由旋转缩放、自动观景、全景/河岸/水流/空地/山后机位、暂停 | `scene.mjs`：固定观察与交互控制；无镜头时间线或视频导出 |
| 方案保存与比较 | 命名另存、刷新恢复、JSON 文件迁移、当前基准与修改同机位切换 | V18；全部构图/水流/环境/镜头；最多 40 项、按来源网址隔离，无云同步、通用撤销或动画同帧恢复 |
| 教学与开发记录 | 八项能力分析、教学参数实验、五步搭建和逐轮截图记录 | 分析模型与真实场景分开；教学参数不直接控制原作 |

## V17 时的待办清单（V18 进度补充）

1. **作品可保存和复现**：统一完整场景配置、保存/加载、导入/导出、版本兼容与错误处理。
2. **修改可比较和撤回**：相同机位与参数基线、前后版本切换、撤销/重做。
3. **布局可创作**：山、河、铁路、建筑与植被分区的空间编辑，以及编辑后的相互约束。
4. **现实地点可参考重建**：尺度/方位标定、地形与路径数据输入；照片参考和可测量复刻需要分别定义精度目标。
5. **质量可持续验收**：固定机位与状态集合、可复现的视觉问题记录、性能和资源释放基准。

V18 已完成第 1 项的版本 1 保存/恢复与输入校验，以及第 2 项的同机位先后比较；版本迁移、通用撤销/重做和同帧比较仍未实现。其他项继续保留为候选。先冻结已有效果，再决定创作工作流和效果修正各自的范围。
