## 静态构建

在仓库根目录执行：

```powershell
node --test projects/004-eanpa-sky/app/lab/*.test.mjs
node projects/004-eanpa-sky/app/build.mjs
```

构建产物位于该项目的 `app/dist/`，由仓库汇总脚本复制到 `site/004-eanpa-sky/`。浏览器根入口为研究页，`lab/` 为实时院落。原版世界链接至上游官方演示；本地 Python 运行器仍保留原版对照。

构建从固定 commit 的入口递归收集运行模块，并显式纳入动态天气模块、月面、星图与天气贴图。当前共 42 个必要上游文件、10043123 字节（约 9.58 MiB），逐个核对长度和 Git blob SHA-1。构建缓存与输出不提交；没有上传完整上游仓库、沙漠地形与大型世界资源。首次干净构建需连接 GitHub 下载固定文件。

静态适配仅调整构建产物的路径：去除站点根地址依赖、按项目子路径解析素材与音频、重建资源大小索引。上游运行文件保留原始字节，宿主源文件仍兼容本地运行器。构建脚本支持 `EANPA_BUILD_CACHE` 指定已有固定版本缓存，仍执行校验。

源码与素材来源见 [项目许可说明](README.md#来源与许可)，构建产物包含引擎与 Three.js 许可、补丁说明和 `runtime-manifest.json`。声音使用本项目已记录的 CC0 录音；未纳入上游的鸟鸣等音频。
