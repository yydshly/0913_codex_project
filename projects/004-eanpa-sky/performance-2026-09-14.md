# 第 23 轮：启动与降雪开销

研究日期：2026-09-14。上游仍为 Eanpa Sky v0.2.1，commit `a197d3dc42577e9b870b471a39d6b1710c5b5633`；上游代码 MIT。此次只修改宿主 `app/lab/`，没有改动上游缓存。

## 改动与取舍

- 远山、林带、草地、泥土和积雪共 8 个材质使用原生天空环境照明，跳过局部探针与屏幕空间反射的复杂材质图。环境贴图仍随昼夜、天气更新；太阳光、云影、灯光和雪覆盖保留。石径、浅洼水面、窗户等仍使用原反射管线。
- 这是一项针对哑光表面的画质预算：这些表面上的局部反射更简化，并非完全等价的渲染优化。没有减少云采样分辨率、增加纹理或取消夜灯。
- 雪花的树冠旋转和椭球碰撞系数每帧预计算；用解析高度查询替代逐粒子的候选数组排序。测试在约 3.6 万组位置与风速、时间、积雪条件下与原查询一致，误差小于 `1e-10`。
- 雪花宽度、透明度随机值改为初始化计算；密度筛选提前，只向实例缓冲连续写入可见雪花。上限仍为 1800，轨迹、消失高度和渐变规则保持。停雪后只剩积雪时不再更新雪花矩阵。

## 本机实测

同一内置浏览器、均衡画质、相同窗口，资源已有本地缓存。不是冷下载或多设备基准。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 页面启动指标（模块就绪后） | 42.315 秒 | 29.22 秒 |
| 导航到场景就绪 | 42.628 秒 | 30.422 秒 |
| 反射与材质编译 | 28.757 秒 | 18.988 秒 |
| 云编译 | 4.813 秒 | 2.971 秒 |

第二次启动复核：页面启动 36.33 秒、导航到就绪 36.576 秒、反射与材质编译 25.130 秒、云编译 4.370 秒。两次运行的 8 个哑光材质策略一致，未记录运行错误。

云编译代码没有修改，时间也出现下降，说明缓存与系统负载会影响结果。因此这些数字只说明本次启动更快，不能把全部差值归因于代码，也不能承诺每次同样提速。

降雪对照固定为 15:30、天空与院落机位、均衡画质、静音。优化前部分积雪（0.628）最近 300 帧提交耗时中位 22.2 毫秒、95 分位 33.1 毫秒，界面 48 帧/秒；优化后部分积雪（0.775）为 11.6 / 18.8 毫秒、58 帧/秒。覆盖量不同，不能视为严格相同渲染负载。优化前充分覆盖（0.995）也能达到中位 12.4 毫秒、95 分位 17.0 毫秒、界面 60 帧/秒，不能宣称旧版雪景一直卡顿。优化后接近完整覆盖（0.970）为中位 11.1 毫秒、95 分位 13.7 毫秒、界面 59 帧/秒。

独立 CPU 碰撞基准每轮 216000 次查询，7 轮交替执行新旧算法，含每帧系数准备。中位耗时从 155.72 降到 106.36 毫秒，减少 31.7%。这是 Node 查询基准，不代表整帧或 GPU 提速。

复现命令：在本子项目运行 `node app/lab/snow-sampling.bench.mjs`。原始浏览器记录与截图见 [资产记录](assets/README.md)。帧提交耗时是等待提交的墙钟时间，不是 GPU 执行时间。

## 验证与边界

13 份测试文件、31 项检查通过；覆盖新旧碰撞一致性、实例连续写入、停雪后无粒子更新但保留积雪、环境贴图替换，以及既有天气、声音、水岸、灯光回归。浏览器观察与最终状态另记于 [验证记录](notes.md)。

当前适合内部研究演示；启动仍有约半分钟编译等待。多设备兼容、长时间内存/显存走势、人工听感仍需专项验证。下一阶段应优先测不同设备和持续运行，依据实际瓶颈决定进一步优化。
