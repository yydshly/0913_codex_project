# 天气覆盖与民宿应用

核查日期：2026-09-14。版本：Eanpa Sky v0.2.1，commit `a197d3dc42577e9b870b471a39d6b1710c5b5633`，代码 MIT。依据固定缓存中 `engine/weather_system.js` 的 `WEATHER` 表及 `src/weathersky.js` 包装层。

## 目前全面吗？

覆盖了固定版本提供的天气预设入口，但不代表覆盖现实世界全部天气，也不代表所有天气与材质组合已经测完。原先首页的“晴天、降雨、雷暴、暮色、夜晚”混合了天气与时间两个维度。

| 维度 | 当前演示入口 | 边界 |
| --- | --- | --- |
| 8 种天气预设 | 无云晴天、晴间多云、太阳雨、阴天、降雨、雷暴、强风暴 Cyclone、暗黑风暴 | 已全部接到“展开参数 → 天气”；本轮新增 clear、sunshower、overcast、cyclone |
| 宿主新增降雪 | 慢落飘雪、屋顶/庭院/树冠/远景积雪、檐下遮挡、轻柔风声 | 复用上游阴天天空；积雪为加速视觉近似，不属于原生第九种预设 |
| 自由云型 | “晴空 · 云影”对应包装层 none，可搭配积云、层云、卷云、无云 | none 是停止天气并保留云配置，不额外算第九种自然天气 |
| 时间 | 0–24 小时、晨光、午后、暮色、夜晚、自动昼夜 | 时间不计入天气数量 |
| 雨后状态 | 水迹自然累积、停雨后保留并逐渐干燥 | 历史纹理近似，没有真实排水与水量求解 |
| 宿主新增冰雹 | 快速下落、按材质衰减反弹、落点敲击、独立声音分层 | 复用阴天天空；固定表面高度近似，没有破碎与持久堆积 |
| 尚未覆盖 |沙尘、独立浓雾天气、冰面、雨雪混合 | 需要新增粒子、材质历史、能见度和声音设计，不能只改按钮名称 |

当前远景雾化是场景渲染的一部分，不等于完整浓雾天气。Cyclone 是强风雨和云幕的外观配置，不是气旋动力学模拟。细雨在上游为旧别名映射到 rain，不应当作独立完整实现。科幻环世界等属于另一类天空环境，保留在原版入口。

上游依据：[天气预设](https://github.com/SkyeShark/Eanpa-Sky/blob/a197d3dc42577e9b870b471a39d6b1710c5b5633/engine/weather_system.js)、[宿主包装层](https://github.com/SkyeShark/Eanpa-Sky/blob/a197d3dc42577e9b870b471a39d6b1710c5b5633/src/weathersky.js)。本地验证另见 [notes.md](notes.md)。

## 实际应用入口：听雨山居

这是一个虚构民宿的可运行展示原型。场景包含入口门架、石径、花园、茶亭、三间客房及院灯；沿客人参观路线演示环境效果。未接入真实民宿、预订、天气 API 或室内行走。

| 体验站点 | 自动配置 | 客人看到什么 |
| --- | --- | --- |
| 01 抵达庭院 | 晴间多云，15:30，入口机位 | 由门架望向茶亭、花园和客房，理解空间布局 |
| 02 花园散步 | 太阳雨，16:00，石径机位 | 日光与局部降雨共存，观察石径干湿与植物 |
| 03 檐下品茶 | 降雨，17:00，屋檐机位 | 桌椅与茶杯、檐外雨幕，以及遮挡后的雨声 |
| 04 夜间归房 | 停雨，23:00，客房机位 | 院灯、窗口暖光、通往客房的路径与保留水迹 |

点击站点或“下一站”切换，最后一站可重新体验。任一站都能手动改天气：修改天气会保留路线站点；左下角提示与按钮根据天气、时间变化。雨天可点击“进入茶亭”，夜间可查看客房归途，风暴提示优先于普通夜游提示。这些按钮实际移动相机，不只是说明文字。时间与天气变化不重建场景，雨后历史继续保留。

声音仍需用户点击开启。每站 12 秒天气过渡，太阳雨仅在局部云下出现降雨，不能以画面某一时刻没有雨丝判断按钮失效。

## 应用层与引擎层的分工

天气引擎负责云、雨、光照、湿润与反射；`stay.js` 负责参观路线和适配规则；`courtyard.js` 提供建筑、植物、灯具、机位；`soundscape.js` 负责声音。可将模型换成真实民宿，并替换路线与内容，再逐步接入业务数据。入住预订、房间信息和订单并不属于天气引擎。

当前路线是镜头导览，没有人物导航、碰撞检测和无障碍路线求解；不能将演示中的檐下视角作为真实雷暴避险建议。更广泛的接入方案见 [扩展路线](extension-roadmap.md)。


## 雨是否只能在乡村表现？

乡村土地便于表现湿色、浅洼积水和泥泞；石径更适合观察水花、薄水膜和反射；屋檐适合表现遮雨与内外声场。雨丝能否看清还取决于局部雨量、观察距离、背景明暗及粒子分布。当前已加入泥地和石径对照及直接雨景机位，收紧近景雨粒子范围。最新迭代已加入局部檐口滴水与落点声，详见 [完整听雨体验](sensory-experience.md)；完整屋面径流、泥浆与脚印尚未实现。

闪电保留在雷暴系统中，首页“观看闪电”会先准备雷暴再触发实际事件；普通 rain 的预设闪电强度为 0。夜晚、阴天和降雨不能自动等同于雷暴。

## 第 16 轮：同机位晴、阴、雨、雪对照

点击“天空与院落”，保持午后 15:30，再依次点击晴朗、阴天、降雨、降雪。天气按钮不改时间、机位和灯光；雷暴保留独立入口。雪从阴天云层渐变进入，雨转雪时先让雨量衰减；露天雪层随时间增加，停雪后慢慢消退。声音需点击开启，稳定降雪使用轻柔合成风声，不播放雪花撞击声。

雪花采用 1,800 个实例化薄片，慢落、摆动和风向偏移；按庭院屋顶与地面高度终止，露天地面与两个屋顶另铺渐变雪层。未新增纹理贴图或阴影贴图；非降雪且无残雪时跳过雪层更新。实现细节、边界与扩展顺序见 [降雪实践](snow-weather.md)。

## 第 17 轮：冰雹与连续雪景

新增冰雹按钮，保留机位、时间和灯光；切换后可选“泥地水迹”看落点、“檐下全景”听屋顶。石径反弹较明显，泥土、水面和残雪吸收更多冲击；敲击声由真实碰撞事件驱动。雪景扩展为现有树冠、林带、草地与山体的朝上表面覆盖，和庭院共用积雪进度。详见 [冰雹与连续雪景实践](hail-and-landscape-snow.md)。
