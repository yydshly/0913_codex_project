# 004 · Eanpa Sky 原版演示运行器

本目录提供固定版本运行器、原版中文适配及独立能力演示。上游引擎缓存保持原始字节；`lab/` 新建程序化庭院，采用较小的天气预算。

当前演示满足阶段研究需求，暂时收尾；待优化内容与尚未验证的范围见 [当前结论与后续优化备忘](../next-steps.md)。

GitHub Pages 研究入口由 `research.html` 构建，实时院落位于其 `lab/` 子路径；构建方式、依赖校验与发布边界见 [发布说明](../publishing.md)。

## 默认体验：檐下全景

当前启动后进入 15:30 降雨与檐下全景。“完整听雨体验”恢复降雨与檐下机位，保留当前时段，下方可选择远山、泥地、檐口机位；右上角可隐藏界面，Esc 恢复。右侧折叠控件开关远景和滴水，近处声音音量独立于主音量。场景新增模块 `lab/rain-experience.js`，详细边界见 [完整听雨说明](../sensory-experience.md)。

灯光行提供“自动／开灯／关灯”，不改变天气、时段和机位。“灯光亮度与区域”可调亮度并单独控制茶亭、步道与客房。选择夜晚后可对照开关效果；自动模式在傍晚渐亮、清晨渐灭。近处水滴与落点圈响应光照，局部灯光为展示近似。

## 看雨与看闪电

点击首页“看泥地雨景”：保留当前时段，进入降雨、低机位观察泥地与石径，等待 12 秒过渡，水迹继续自然累积。点击“观看闪电”：保留当前时段，进入雷暴，过渡后约 1 秒排队触发上游真实落雷；天气已就绪时再次点击可重复观察。声音需另行开启。若切走雷暴，待触发演示会取消；暂停时计时也停止。

## 当前入口：听雨山居

打开 `/lab/` 后选择四站民宿体验，或按“下一站”参观。每站配置机位、时间和天气；手动切换天气仍保留站点，左下角按钮根据雨天、风暴、夜间变化并可实际移动镜头。全部天气在展开参数后选择，覆盖清单在“天气覆盖说明”。`lab/stay.js` 管理路线及适配规则，`node projects/004-eanpa-sky/app/lab/stay.test.mjs` 验证天气入口、机位和规则优先级。

## 独立能力演示

入口是一座带屋檐、石径、树木、花坛和夜灯的小院。晴天、降雨、雷暴、暮色、夜晚按钮保持当前机位，方便同场景比较；天气过渡 12 秒，地面湿润随后自然累积。场景接入和扩展路线见 [深入说明](../extension-roadmap.md)。

上方“观察主题”提供建筑雨景、落日景观、雨中材质三种配置；它们使用同一个庭院，自动设置天气、时间和机位，不自动开启声音。参数默认收起，通过“展开参数”调整；手动改变天气或时间后回到自由观察。机位平滑切换，拖动会中断。点击“可以用在哪里？”查看应用说明。配置与说明位于 `lab/scenarios.js`，详细分析见 [使用场景](../use-cases.md)。

声音：右下角点击“开启声音”，默认音量 25%；雨声跟随引擎 GPU 采样的局部雨量，屋檐遮挡会降低音量和高频，雷暴触发方向性延迟雷声。刷新后需再次开启，页面隐藏、暂停、记录弹窗会暂停音频。实现位于 `lab/soundscape.js`，自然雨声与雷声首次开启时加载约 0.4 MiB，轻微风声仍为合成；可选择仅雨声、仅风声、仅雷声，授权见 [声音来源](../assets/audio/README.md)；位置与传播参数验证：`node projects/004-eanpa-sky/app/lab/soundscape.test.mjs`。

启动服务后访问 [听雨小院](http://127.0.0.1:8044/lab/)。源码位于 `lab/main.js`（模块接入、串行渲染、控制与记录）、`lab/courtyard.js`（几何与机位）、`lab/index.html` / `lab/lab.css`（双语界面）。许可文本随入口提供。

先看晴天空影，再选降雨并等待 12 秒；切“雨后石径”和“檐下听雨”观察，最后切晴天看保留湿润。运行预算可选 60 帧上限的均衡档或 30 帧上限的省电档；帧率上限不代表设备保证值。实践记录弹窗显示操作历史，可下载 JSON。记录存于本页会话，刷新前请导出。

仅运行提取版时无需 `--prefetch-code`，直接 `python projects/004-eanpa-sky/app/serve.py`，再打开 `/lab/`，按需获取实际使用模块。原版入口 `/` 仍可用。详情见 [能力提取实践](../extraction.md)。

## 启动

需要 Python 3.10+，无额外 Python 或 npm 依赖。在研究仓库根目录运行：

```powershell
python projects/004-eanpa-sky/app/serve.py --prefetch-code
```

访问 http://127.0.0.1:8044/ 。`--prefetch-code` 先缓存源码与渲染器，材质、模型和音频仍按页面请求获取。端口被占用时，可用 `--port 8045`，并访问对应端口。前台运行按 Ctrl+C 停止。

需要支持 WebGPU 的浏览器。首次加载包括下载、纹理处理、场景构建与着色器编译，加载文字会显示阶段。浏览器不支持 WebGPU 时不能切到 WebGL 冒充原版效果。建议先用默认 Balanced；Quality 面板的 FPS 是目标值。

## 原版操作（中文 / 英文控件对应）

- Skybox：Earth、Orbital / Halo、Earth 5129323011 CE (Red Giant)。切换可能重新出现加载界面。
- Cloud Type：Clear Sky、Cumulus、Stratus、High Cirrus。独立比较云型时选 Weather → None。
- Weather：None、Fair、Sunshower、Overcast、Rain、Storm、Cyclone、Dark Storm。过渡通常需要约 45 秒。
- Time of day：拖动时间滑块；day/night cycle 自动推进，周期可选 60 / 120 / 300 秒。
- 雷暴状态下使用 test lightning strike 观察落雷；晴天不能据按钮判断闪电失效。
- 单击场景锁定视角；鼠标环顾，WASD 行走，Shift 奔跑，Space 跳跃，F 手电筒，滚轮缩放，Esc 释放鼠标。

## 文件与版本

- `research-ui.js` / `research-ui.css`：中英界面与记录弹窗，不修改原始控件值或引擎 API。
- `practice.html` / `practice.js` / `practice.css`：双语实践记录、资源图表、原理与截图入口。
- `resource-report.json`：已校验的磁盘缓存统计；`inspect-resources.py` 用于重新统计。
- `serve.py`：仅绑定 127.0.0.1 的多线程资源服务，匹配上游 JS/MJS/WASM 内容类型和 `/__log` 本地日志接口。
- `upstream-lock.json`：上游 commit、版本、文件大小和 Git blob SHA-1。升级必须显式更新清单；不会自动跟随 main。
- `.cache/<commit>/`：按需保存的原版文件，被根 `.gitignore` 忽略，不属于提交内容。
- `.cache/browser-console.log`：原版程序发送到本机的运行日志。
- `/__research/status`：本地服务标识、固定 commit 与本进程已验证的缓存文件数。

所有上游文件下载后核对 Git blob 哈希，内容一致才写入正式缓存；下载失败返回 502，修复网络后刷新页面重试。服务器只允许清单内的路径，不提供任意 URL 代理或目录列表。首次运行仍依赖 GitHub raw 的网络可达性；已缓存的场景可以复用，但尚未访问的天空与资源仍需联网。

启动命令已验证，原版 Earth / Orbital / Halo / Shieldworld 切换成功，并已保存昼夜和天气对照截图。实际运行与截图范围见 [验证记录](../notes.md)。本轮没有发布构建入口，根站点构建会跳过本项目。

### 新增降雪

`/lab/` → 天空与院落 → 保持午后，依次切换晴朗、阴天、降雨、降雪。积雪持续累积，停雪后消退；不是瞬间切换贴图。声音需点击开启。上游仍为固定版本，新增效果位于 `lab/snow-weather.js`；无需新增依赖或贴图下载。

相关检查：`node --test lab/snow-weather.test.mjs lab/soundscape.test.mjs lab/stay.test.mjs`（在本目录执行）。

### 冰雹与整片雪景

天气选“冰雹”，再选“泥地水迹”或“檐下全景”；声音可单独选“仅冰雹声”。降雪会同时覆盖树冠、草地、林带和山体朝上表面。新增检查：`node --test lab/hail-weather.test.mjs`。实现与边界见上级 `hail-and-landscape-snow.md`。

## 第 19 轮操作修复

设置默认收起，从左上“天气与设置”展开。暂停按钮常驻，暂停时调整天气、时间、灯光或机位会继续播放；手动环顾标记“自由视角”，记录包含实际相机位置与目标点。冰雹增加远处整体声场，保留近处材质敲击与声音分层隔离。表面查询集中到 `lab/surface-state.js`，详见 [修复说明](../fixes-2026-09-14.md)。
