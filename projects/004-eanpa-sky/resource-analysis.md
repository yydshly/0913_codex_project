最大的两份地表 KTX2 文件分别约 71.58、67.77 MiB，合计约 139.4 MiB，保存 14 层 2K 地表颜色/高度和法线/粗糙度/AO。完整演示的素材是下载体积主因，单纯压缩 JavaScript 的收益较小。

## 为什么运行也重

1. **体积云需要反复采样。** 均衡档参数为 44 个视线采样、14 个光照采样和 3 个云 pass，结合降分辨率、密度/光照缓存。实际成本受缓存、跳步、提前退出和画面覆盖影响，不能把这些数直接相乘当成精确每像素工作量或毫秒数。
2. **场景会经过多轮渲染。** 太阳阴影、云影、天空环境反射、局部反射、环境遮蔽和降雨表面捕获都有额外成本。均衡档还配置 10,000 个雨粒子和 700 个水花。
3. **GPU 常驻资源多。** 模型缓冲、纹理、mipmap、深度图、多张浮点渲染目标和历史缓存共同占用显存。磁盘上的压缩字节不能直接代表 GPU 大小；KTX2 可能转码为 GPU 压缩格式，不能一律假设解压为 RGBA。
4. **启动不只有下载。** 场景构建、纹理处理与上传、TSL 图生成、驱动着色器编译、反射和首帧准备都可能耗时。切换天空会重新准备部分资源。真实 RAM/VRAM 峰值和每个通道的 GPU 耗时尚未测量。

算例：一张未压缩 4096×4096 RGBA8 纹理为 64 MiB，完整 mipmap 后约 85.3 MiB；这不是本项目实际显存读数。上游记录 Performance 默认三组云全景目标合计约 60 MiB：减少重复计算也需要额外缓存空间。

降低天空画质仍保留地形、建筑和环境遮蔽，并不等于整场景资源同步缩减。要降低下载体积，应优先按需加载、减少地表层数与分辨率、替换大型模型；要降低渲染计算，再调整云、反射、阴影和降雨预算。本轮没有实施这些画质或资源裁剪。

依据：[画质配置](https://github.com/SkyeShark/Eanpa-Sky/blob/a197d3dc42577e9b870b471a39d6b1710c5b5633/engine/quality_presets.js)、[云缓存取舍](https://github.com/SkyeShark/Eanpa-Sky/blob/a197d3dc42577e9b870b471a39d6b1710c5b5633/docs/SKY_SYSTEM_INTEGRATION.md)、[上游已知限制](https://github.com/SkyeShark/Eanpa-Sky/blob/a197d3dc42577e9b870b471a39d6b1710c5b5633/KNOWN_ISSUES.md)。

## 效果与实现原理

| 效果 | 原理 | 边界 |
| :--- | :--- | :--- |
| 体积云 | 多层三维噪声定义密度，视线 Ray Marching 累积光的衰减与散射，风移动密度场 | 视觉密度场，不是气象预测或完整流体求解 |
| 昼夜 | 按太阳高度插值预设颜色和亮度，统一驱动天空、云、主光和环境光 | 含美术设定，不是完整真实大气求解 |
| 云影 | 沿光线积分云遮光程度，写入共享纹理，场景表面按世界坐标采样 | 范围有限，云内部采用近似；默认约 10 Hz 更新 |
| 降雨与遮雨 | 相机附近的世界空间雨粒子，沿雨方向捕获第一层表面的深度和法线 | 需要额外捕获，不是每滴雨的完整物理模拟 |
| 水迹与水洼 | GPU 历史纹理记录湿润和积水，再改变材质粗糙度、法线与反射 | 不模拟径流、排水、困水体积及完整移动物体水量历史 |
| 环世界与红巨星 | 曲面地形、材质、遮光，以及大角直径光源近似，配合护盾和破碎月球几何 | 额外资产与渲染管线；本轮没有逐一验证所有天体视角 |

Performance 使用分批捕获、重投影和插值的云全景；Balanced/High 保留实时云体积。性能档牺牲精细形变、多层视差以及快速穿云的准确性。

依据：[天空源码](https://github.com/SkyeShark/Eanpa-Sky/blob/a197d3dc42577e9b870b471a39d6b1710c5b5633/engine/sky_system.js)、[降雨与地表水](https://github.com/SkyeShark/Eanpa-Sky/blob/a197d3dc42577e9b870b471a39d6b1710c5b5633/engine/RAIN.md)。

## 我们实际改了什么

第一轮跑原版，保存 7 张实测截图。本轮增加默认中文/英文切换、演示内实践记录弹窗、资源统计与解释页；不改变上游渲染模块和场景逻辑。

界面适配保持原始控件 ID 和选项值，因此语言切换不会触发天空重建或重置天气过渡。语言偏好保存在本机，记录页关闭后继续原场景。原始缓存文件仍校验哈希；中文主入口只追加本地 UI 脚本和样式。未汉化对照入口 `/original/` 仅补充资源路径基准。
