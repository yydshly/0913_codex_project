# 声音来源与处理

2026-09-14 核实：[Rain & Long Thunder](https://opengameart.org/content/rain-long-thunder)，作者 **WuxiaScrub**，页面标注 **CC0**。雨声和雷声来自同一段自然录音；不使用上游演示中授权不同的其他音频。

- `rain-garden.ogg`：截取原录音 2–19 秒，避开约 20 秒后的主要雷声；去直流偏移、调整增益、首尾交叉混合，得到 15.5 秒循环。
- `thunder-natural.ogg`：截取 20.7 秒至结尾，调整增益和首尾淡入淡出，得到约 23.67 秒雷声；该片段保留录音中的雨声底噪。
- 两个文件合计 418,755 字节，约 0.40 MiB；首次开启声音才加载。雨声解码后再做 15 毫秒边界窗，避免循环接缝突变。
- 运行时使用低通滤波、音量渐变和动态压缩；风声仍是低音量合成。屋檐声是录音的滤波近似，不是不同屋顶材质的实录。

源文件与输出 SHA-256、解码时长、峰值及 RMS 见 [source-and-checks.json](source-and-checks.json)。使用 NumPy 处理 PCM、FFmpeg 编码 Ogg Vorbis；原始录音和 WAV 中间文件仅保存在忽略的本地缓存。

数值与浏览器链路检查不能代替扬声器或耳机试听。当前雷声只有一个录音变体，连续风暴仍可能听出重复；后续可增加明确授权的不同距离、不同屋顶材料录音。


2026-09-14 完整听雨迭代：在上述自然录音基础上新增树叶滤波层和低音量合成的石面、土面、屋顶冲击短音。落点事件驱动音色、距离衰减和声道方向，可选“仅细节声”检查。没有新增外部音频文件，也不把这些短音描述为各材质实录。
