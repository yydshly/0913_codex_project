# 项目图片与素材

存放当前子项目的封面、运行截图、流程图和必要演示素材。

| 建议名称 | 用途 |
| :--- | :--- |
| `cover.webp` 或 `cover.png` | 首页预览使用的代表图 |
| `01-overview.png` | 主要界面 |
| `02-workflow.png` | 核心操作流程 |
| `architecture.svg` | 架构或模块关系图 |

这些名称仅为约定，目前没有真实图片。图片就绪后再在 README 中添加引用。

- 使用相对路径，附带具体的画面说明。
- 截图尽量压缩，长视频以外部链接展示。
- 记录上游图片来源和许可；运行截图标注对应的研究版本。
